# One Line, One Laugh

A single self-contained one-liner for the make.fun "One Line, One Laugh" contest (sponsor coral-404 edition). The joke sets up a search for life purpose, then turns: the life coach hired to help quits to become a monk — and that, honestly, feels like an answer.

## Run

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if needed).
